🎯 ГЛАВНОЕ - КАК ИСПОЛЬЗОВАТЬ:

  1️⃣  В вашем main.py:
  
      from zkill_panel import ZkillPanel
      
      class MyApp:
          def __init__(self):
              self.zkill_panel = ZkillPanel()
  
  
  2️⃣  Когда нужно открыть персонажа:
  
      self.zkill_panel.open_character_in_compact(character_id, character_name)
  
  
  3️⃣  ГОТОВО! Откроется окно с:
      - Ником и ID персонажа
      - Табы: Overview, Kills, Losses
      - Таблица с датой, кораблем, локацией, противником
      - Всё за <1 сек ⚡

💾 ОСНОВНЫЕ ФУНКЦИИ:

  zkill_panel.open_character_in_compact(char_id, char_name)
  ├─ Загружает kills/losses с zkillboard API
  ├─ Парсит data с zkill_table_model
  ├─ Отображает в компактной таблице
  └─ Кэширует ESI данные на 24ч

  zkill_viewer.open_character()
  ├─ Открывает окно с 3 табами
  ├─ Показывает аву, ник, ID
  └─ Заполняет таблицы данными

  KillsLossesTable.load_data(rows)
  ├─ Принимает список словарей
  ├─ Отображает в PyQt таблице
  └─ Готово для сортировки/поиска

📞 ВОПРОСЫ?

  Q: Какой файл прочитать первым?
  A: QUICKSTART.txt или MAIN_WINDOW_TEMPLATE.py

  Q: Как добавить свои колонки в таблицу?
  A: Отредактируйте zkill_compact_table.py, метод load_data()

  Q: Как загружать больше данных?
  A: Измените limit в get_recent_kills/losses в zkill_client.py

  Q: Работает ли автоматическое кэширование?
  A: Да, ESI кэширует 24ч, killmails кэшируют 1ч

  Q: Нужен ли интернет?
  A: Да, для API запросов (zkillboard + ESI)
